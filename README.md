# CPE2600_System_Calls

Provides commands utilizing system calls to print information about the system, files, and process modification.

## Commands

### \> info

Prints information about the device running the command

### \> finfo

Prints file information of file path passed as an argument to the command.

### \> pinfo

Prints information about a running process specified by the pid passed to the command, or the current process if none specified.

### \> pmod

Modifies its own process to increase its schedule priority. Requires privileges.
